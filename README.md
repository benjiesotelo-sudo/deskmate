# Deskmate

The colleague at the next desk.

Deskmate is a local-first office app that keeps an office's documents filed consistently, documents its processes with real examples, and onboards newcomers through Tams, an assistant that answers from the office's own documents using a model running on the machine itself.
It keeps working when the internet is gone.

Built for the App Builders PH Local AI Hackathon, 9 to 10 October 2026.

Setup instructions, disclosures, and the local-versus-cloud breakdown are filled in as the build lands.
